# crm-alhaouz

الموقع الإلكتروني للمكتب الإقليمي للهلال الأحمر المغربي بالحوز.

**الموقع المنشور:** https://crm-alhaouz.online

المستودع مربوط بـ Vercel: كل `git push` إلى الفرع `main` ينشر نسخة جديدة من الموقع تلقائيًا خلال دقيقة تقريبًا.

## المحتوى

- من نحن والتشكيلة الجديدة للمكتب (الجمع العام التجديدي، 18 ماي 2025)
- خارطة الطريق 2025–2028 وعرض التكوين
- مجالات التدخل، وملف زلزال الحوز، والمسار من 2022 إلى 2025
- دليل تفاعلي للإسعافات الأولية، ومعرض للصور، واستمارة للتطوع عبر واتساب

المحتوى والصور مأخوذة من مجلة «موجز أنشطة المكتب الإقليمي 2022/2025».

## لوحة التحكم

عدّل المحتوى من **https://crm-alhaouz.online/admin** (تسجيل الدخول بحساب GitHub له صلاحية الكتابة على المستودع).
كل حفظ يُسجَّل في المستودع وينشر الموقع تلقائيًا.

- المحتوى محفوظ في `content/*.json` (الأخبار، المكتب، الدورات، الأرقام، المسار، المعرض، المجالات، الشركاء، الإعدادات).
- الصور المرفوعة من اللوحة تُحفظ في `images/uploads/`.
- تسجيل الدخول يمر عبر `api/auth.js` و`api/callback.js`، ويحتاج متغيرَي البيئة `GITHUB_CLIENT_ID` و`GITHUB_CLIENT_SECRET` في Vercel.
- بعد أي تعديل من اللوحة، نفّذ `git pull` قبل التعديل على الحاسوب.

## التشغيل محليًا

موقع ثابت (HTML وCSS وJavaScript) لا يحتاج إلى أي بناء:

```bash
python -m http.server 5178
```

ثم افتح http://localhost:5178

## الملفات

- `index.html`: بنية الصفحة والنصوص
- `styles.css`: التصميم والوضع الليلي والتجاوب مع الهاتف
- `app.js`: البيانات (المجالات، المسار، المعرض، دليل الإسعاف) والتفاعل
- `images/`: الصور المستخرجة من المجلة
