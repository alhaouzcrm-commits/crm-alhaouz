# الهلال الأحمر المغربي — المكتب الإقليمي بالحوز (crm-alhaouz)

تطبيق React عصري للموقع الرسمي للمكتب الإقليمي للهلال الأحمر المغربي بإقليم الحوز، مبني باستخدام React 19 وVite وTypeScript وTailwind CSS مع الحفاظ الكامل على الهوية البصرية، المحتوى الإنساني، والتفاعلية الميدانية.

## المميزات والخصائص

- **شريط أرقام الطوارئ (SOS):** وصول فوري لأرقام الوقاية المدنية (15)، الإسعاف الطبي (141)، الشرطة (19)، الدرك الملكي (177) وأرقام المكتب الإقليمي مع الاتصال المباشر.
- **التصميم المتجاوب والوضع الليلي:** دعم كامل للغتين والنمطين الفاتح والداكن (Light/Dark mode) وحفظ التفضيل محليًا.
- **الحصيلة بالأرقام:** عدادات تفاعلية متحركة تعكس إنجازات وتدخلات الهلال الأحمر بإقليم الحوز.
- **الأخبار والجمع العام والمكتب الإقليمي:** استعراض تفاصيل الجمع العام التجديدي (18 ماي 2025)، تشكيلة المكتب الجديد، خارطة طريق 2025–2028، وعرض الدورات التكوينية.
- **نافذة منبثقة تفاعلية (Modal):** لقراءة الأخبار كاملة وعرض تفاصيل وتفاصيل مجالات التدخل والصور التوضيحية.
- **ملف زلزال الحوز (شتنبر 2023):** إحصائيات الإغاثة والتدخلات الميدانية مع جدول تفاعلي للأماكن وأنواع المساعدات («أين تدخّلنا؟») ومعرض لصور عمليات الإنقاذ.
- **سلسلة التكوينات:** رسوم بيانية تفاعلية بمقياس لوغاريتمي توضح عدد المستفيدين حسب نوع التكوين.
- **المسار (2022 – 2025):** خط زمني تفاعلي مع إمكانية التصفية حسب السنة لجميع المحطات والمبادرات.
- **دليل الإسعافات الأولية التفاعلي:** خطوات قابلة للتأشير ومتابعة نسبة الإنجاز، مع **ميترونوم صوتي حقيقي (110 ضغطة/دقيقة)** لإنعاش القلب (CPR) وقلب نابض مرئي.
- **معرض الصور والشاشة الكاملة (Lightbox):** تصفح مصنّف للصور مع عارض شاشة كاملة متجاوب، تحكم بلوحة المفاتيح والأسهم، وتسميات توضيحية.
- **استمارة التطوع المباشرة:** تعبئة طلب التطوع وإرساله فورًا عبر تطبيق واتساب برسالة منسقة جاهزة للمكتب الإقليمي.
- **التسجيل في الدورات التكوينية:** دمج مباشر لاستمارة التسجيل الإلكترونية مع زر بديل للتسجيل عبر واتساب.
- **شريط الشركاء المتحرك:** شريط متحرك انسيابي (Marquee) يعرض كافة الشركاء المؤسساتيين وجمعيات المجتمع المدني.

## البنية التقنية

- **Framework:** React 19 + TypeScript
- **Bundler & Dev Server:** Vite 6
- **Styling:** Tailwind CSS + Custom CSS Variables & RTL Arabic typography (`Tajawal`, `Reem Kufi`)
- **Static Assets:** `public/images/` و `public/content/`

## التشغيل والتطوير

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء النسخة النهائية للإنتاج
npm run build
```
